Install guide

Install in under a minute.

Windows install · real recording
Windows
  1. Download ClipCutter-…-windows-x64-setup.exe and open it.
  2. A blue "Windows protected your PC" box appears because the app isn't code-signed yet. Click More info, then Run anyway.
  3. Click Next → Install → Finish. ClipCutter opens in your browser.
macOS
  1. Download the .dmg and open it.
  2. Drag ClipCutter into Applications.
  3. The first time, right-click ClipCutter → Open → Open. After that, open it normally.
Android (beta)
  1. Download the .apk on your phone.
  2. When asked, allow Install unknown apps for your browser.
  3. Open ClipCutter, paste a link and tap Make clips. Keep the phone charging for long streams.

Troubleshooting

Downloads fail or say "HTTP 403"

Sites like YouTube change often. Click ↻ Update downloader at the bottom of the ClipCutter page, then try again.

"No space left on device"

The whole video is downloaded once before clipping. Free a few GB, or clip shorter videos.

It's stuck on the speech model

The first time a video has no captions, ClipCutter downloads a speech model (about 1.6 GB on a computer). It only happens once.

Still stuck?

Open an issue on GitHub or comment on the YouTube video and we'll help.
